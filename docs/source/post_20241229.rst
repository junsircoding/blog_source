地图掩模
========================================

在涉及到气象、金融、社科等等领域的项目中，经常需要在地图上把数据可视化的展示出来。
比如全球的气温情况、全国的 GDP 数值情况，以及全国的人口分布情况等等。
这样的图不仅比较直观也显得很专业，制图的过程其实也比较有意思。
这其中有一个很高频的需求是就是把地图上的某些区域按照我们的需求掩盖掉，只显示我们需要的部分，
这个需求大致可以概括为「地图掩模」。

画这张全球气温分布图的思路很简单，先用基于 Matplotlib 的 Cartopy 画出地图，再把栅格数据以填色、等值面等形式叠加到地图上即可。
那么如果我现在只想展示山西省的气温情况该怎么做呢？

有两个思路：第一，在现在的图的基础上，增加一个图层，把山西省之外的部分掩盖掉；第二，把数据中山西省之外的部分剔除掉。

第一种方法比较简单。
Cartopy 库中包含的 Nature Earth 地图数据，分为人文维度（Culture）和物理维度（Physics）。
人文维度就是基于世界各国政府的政治主张以及国际共识，划分出的大洲界限、国家界限、行政区域界限。
物理维度则是基于大自然实际的海洋、河流、山脉、峡谷等划分出的界限。

如果我们要把所有的海洋掩盖掉，只要把物理维度中的海洋元素设置成白色，就可以把它掩盖掉，只剩下陆地区域。
「把海洋部分掩盖掉」这是一个掩盖物理区域的需求，而「把山西省部分掩盖掉」则是一个掩盖人文区域的需求。
我们逐个遍历 Culture 目录中所有的区域，把它们都涂成白色，只把山西省跳过，这样最后露出来的区域就只有山西省。

但这样就有一个问题。

第二种方法。

我们可以制作一个山西省的掩膜数据，把山西省范围的值置为 ``1`` ，把其他范围的值置为 ``0`` 。
然后把展示数据和掩膜数据的精度插值统一一下（ ``xarray.interp()`` ），把展示数据中山西省之外的数据设置成空值（ ``xarray.where()`` ）。
这样通过直接修改展示数据的方式，就实现了需求。

这两种方式各有优缺点。
第一种方式画素速度比较快，因为它只是简单的给某些多边形设置颜色而已。
但如果我们地图是使用了 ``MapBox`` 或者高德地图这样元素比较丰富的底图，那么使用第一种方式的话，这些地图部分也会被盖掉。
这时就必须使用第二种方式，直接修改数据比较符合逻辑，但是制作掩模比较耗时，耗时的长短与绘图的精度正相关。
如果要显示的区域比较小，比如是一个省或者一个市，那么数据精度就需要很高。栅格数据本质上就是一个一个小方格，无论把精度设置的多么高，
理论上如果把图放大看边缘，一定还是可以看到锯齿。
如果展示的区域比较大，比如是一个大洲或者国家，那数据精度不必很高，只要展示出来看不到边缘的锯齿即可。
所以实际使用时，要综合考虑需求，根据显示区域的大小以及展示效果，设置合适的数据精度。
